# goctl templates

Snapshot generated by goctl 1.10.2 (`goctl template init`), retaining API/RPC templates only.
Generation always passes `--home templates/goctl`, so personal templates cannot affect output.
Templates inherit upstream go-zero's MIT license (see LICENSE). The API handler template maps request parsing errors through GoSeed xerr. Upgrade templates and tool versions together,
review the diff and run `make verify-gen`. Never run template init over local changes.
