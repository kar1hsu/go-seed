# 文件与异步任务验证记录

2026-10-30 在本地开发环境执行。默认本地私有存储、MySQL 8、Redis 8、Asynq 0.26.0；不代表已在生产或远程 S3 环境验收。

| 检查 | 结果 |
| --- | --- |
| `make check test build` | 通过，包含 Go 格式/边界/vet、前端类型与格式、单元测试、五个 Go 进程和前端生产构建 |
| `make verify-gen` | 通过；重复生成一致，新增契约不会覆盖已有 handler/logic/依赖装配 |
| `make test-rbac` | 通过，完整临时数据库测试含 race，约 233 秒 |
| 文件与任务专项 race | 通过；最后调整后的文件隐私、重复任务、租约恢复、撤权、重试、审计回滚、小时去重与真实 Asynq 消费约 49 秒 |
| 失败导出清理与重试专项 | 通过；已清理结果重新分配对象键，历史消息不能修改新批次 |
| `make test-storage` | 本地原子写并发、大小边界、路径边界和 S3 条件请求协议测试通过；真实 S3 roundtrip 未配置端点，明确跳过 |
| `make migrate sync-resources` | 新增 SQL 迁移与权限同步成功，原有账号与角色授权保持 |
| Compose 构建与启动 | 五个 Go 进程、gateway、MySQL、Redis 共八个容器健康 |
| `make smoke auth-smoke rbac-smoke` | 通过，含两个 API、RPC、存储/队列进程就绪、会话与管理链路 |
| 大于默认 API body 上限的传输 | HTTP smoke 使用约 544 KB 文件通过；网关另外上传 464000 字节文本，通过 SHA-256 校验 |
| 浏览器验收 | 文件/任务页面、小时清理记录、导出自动完成、文件与 CSV 下载通过；下载内容校验一致，控制台无警告或错误 |
| 390px 窄屏 | 页面宽度保持 390px；筛选、工具栏、固定操作列与表格局部滚动正常 |

数据库测试使用随机临时库，真实 Asynq 测试使用随机队列，结束后只清理自身范围。HTTP 测试使用随机账号/资源名；浏览器验收创建的文件、导出、相关审计及下载副本均已清理。保留系统正常产生的小时任务记录。

最初的 HTTP 尝试发生在旧容器尚未切换时，新接口返回 404；容器更新后重新执行通过。S3 真实服务测试尝试拉取隔离 MinIO 镜像时，官方镜像仓库返回未授权，未启动外部存储；最终提供独立测试端点方式，不能把协议模拟测试报告为真实 S3 验收。

实现范围及运行限制见[文件与任务](files-and-tasks.md)。本批没有实现任意 cron 编辑器、过期认证会话清理或业务开发样板。
