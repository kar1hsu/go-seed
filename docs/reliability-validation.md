# 可靠性修复验证

2026-10-30，在本项目 MySQL、Redis 和完整 Compose 上完成验证，包含侧边栏稳定性修复。

## 修复范围

| 问题 | 处理及回归 |
| --- | --- |
| 长文件名写审计失败 | system 00006 将 target_name 扩为 180 字符；真实数据库与 HTTP 上传/下载/删除验证 180 字符名称 |
| outbox 被归档 ID 阻塞 | 独立 delivery 序号、CAS 投递租约、新 TaskID；验证业务 attempts 未增长时仍可重投、竞争投递不能重复占用同一序号 |
| 匿名登录/注册配额封锁其他来源 | 按可信 IP / IP+账号限流，服务凭证保护 IP metadata；验证代理头防伪、配额隔离、随机账号不能绕过 IP 配额 |
| 密码计算与原密码猜测 | 每服务 4 个并发密码操作、已认证账号改密 5 次/分钟；验证 gate 上限/取消和两个领域的改密限流入口 |
| 保留已停用角色失败 | 已关联且仍处于操作者管理范围的停用角色可保留；新增停用角色仍拒绝 |
| 网络错误误登出、时钟偏差 | 503/网络故障取消路由切换并保留会话；服务器 Date + 单调时钟计时；401 尝试刷新，GET/HEAD 最多重试一次，写请求不重放 |
| 刷新结果丢失 | 随机重试标识、60 秒恢复窗口、后继 token 必须未消费；验证同一结果恢复、并发恢复、错误标识/过期/后继已消费仍撤销，以及旧客户端兼容 |
| worker 优雅退出被截断 | Asynq 8 秒、go-zero 20 秒、Compose 30 秒；真实子进程收到 SIGTERM 时完成 6 秒在途任务后正常退出 |
| 下载缓冲整份文件 | 仅下载路由关闭框架响应缓冲，32 KiB 分块输出和 60 秒读/写期限；验证 EOF 前已收到首块、取消关闭阻塞读取、真实网关下载内容一致 |
| 迁移 2 秒读超时 | 独立迁移连接、10 分钟命令上下文；验证超过 2 秒的 SQL 可完成且显式上下文仍可取消 |
| 生产配置保护 | Mode 环境变量，pro 强制 Secure Cookie / HTTPS Origin / RPC TLS；验证拒绝不完整配置、正确证书握手、错误服务名拒绝 |
| 清理失败阻塞后续对象 | 失败对象延后一小时并继续；验证后续对象删除、失败对象不会占满下一批 |
| 一致性与运维 | LIKE 转义、控制字符校验、RBAC 无变化提交不改审计/版本；审计时间与偏移上限、可配置保留期默认不删除；S3 API 自身 spool 清理、worker 去除签名密钥、安全事件和队列错误日志、文件索引、重启与健康退出、CSP 等响应头 |
| 前端交互 | 同查询请求合并、错误保留页码、hash 不重挂载、后台页签关闭/刷新、UTF-8 密码长度、HTTP 下 UUID 生成、保存错误可重试、懒加载失败提示 |

## 使用边界

生产 TLS 使用测试证书验证握手与主机名校验，没有在真实域名部署 HTTPS。实际部署需按[生产配置](production.md)注入证书和密钥；本地仍使用 dev 模式。S3 覆盖协议模拟与临时目录清理，本批未配置外部 S3 实例。

同一刷新请求仅在 60 秒内且后继令牌未消费时恢复；超出条件保持重用保护，不能保证任意时长离线后恢复。审计默认保留全部历史；非零保留天数应由运维确定归档策略后配置。

Cookie 路径、管理员到 member-rpc 的受控授权校验、member readiness 的跨域依赖等架构选择保持现有设计；未把它们当作已确认缺陷修改。
